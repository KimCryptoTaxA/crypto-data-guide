Pulling your exchange & wallet transactions

Find each exchange, wallet or app you used and follow its steps. Most sources offer a read-only API key, a CSV export, or both. Wallets only need a public address or XPUB key.

Before you send anything

  1. Read-only only. Never enable trading, withdrawal or transfer permissions on an API key.
  2. Paste keys as text into a Word document: API key, secret key, and passphrase or customer ID where the steps ask for one. No screenshots, no PDFs.
  3. Pull full history, from your very first transaction to the end of the latest tax year. Some exchanges cap each export at 3 or 12 months, so run several exports to cover everything.
  4. Upload everything to your ShareFile folder named Last Name, First Name – Crypto Files.
  5. Can't find your source? Use the Manual Entry Spreadsheet below, one file per unsupported source.

Manual Entry Spreadsheet

Use this for any exchange, wallet or platform we can't pull automatically. Download the template, fill it in with Excel or Google Sheets, and send it back to us.

  1. Make one file per source, and put the source's name in the Exchange column on every row.
  2. Enter every transaction from your first one to the end of the latest tax year, one transaction per row.
  3. Keep the header row exactly as it is and save the file as CSV.
  4. Upload it to your ShareFile Crypto Files folder.

Column guide

ColumnWhat to enter
TypeRequiredWhat happened, e.g. Trade, Deposit, Withdrawal, Income, Staking, Airdrop, Mining, Spend, Gift, Lost.
Buy AmountAmount you received. Leave blank for a withdrawal.
Buy CurrencyTicker of what you received, e.g. BTC, ETH, USD.
Sell AmountAmount you gave up or sent. Leave blank for a deposit or income.
Sell CurrencyTicker of what you gave up.
FeeFee paid, if any.
Fee CurrencyTicker the fee was paid in.
ExchangeName of the platform or wallet, the same on every row of this file.
Trade-GroupOptional label to group rows, e.g. an account or strategy name.
CommentAnything that helps us, e.g. "bought with card" or "moved from Ledger".
DateRequiredDate and time of the transaction, as YYYY-MM-DD HH:MM:SS (24-hour).
Liquidity poolOptionalPool name, if the transaction was a liquidity pool deposit or withdrawal.
Tx-IDOptionalBlockchain transaction hash or the platform's order ID.
Buy Value in Account CurrencyOptionalUSD value of what you received at the time. Leave blank or 0 and CoinTracking calculates it.
